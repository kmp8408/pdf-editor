📄 PDF書き込みくん (ver7.0.1) 操作マニュアル
ブラウザだけで安全・快適にPDFへ文字や図形を書き込み、新しいPDFとして保存できる軽量Webツールです。手書き機能などの複雑な操作を省き、業務で本当によく使う機能だけに絞り込んでいます。
🌟 主な特徴
•	インストール不要：ブラウザ（Google Chrome / Microsoft Edge など）で開くだけで即座に動作します。
•	情報漏洩ゼロの安全性：読み込んだPDFデータは外部サーバーへ送信されず、すべてお使いのパソコン内（ブラウザ）で完結して処理されます。
•	クリックした場所へ直接配置：ツールを選んでPDF上の置きたい場所をクリックするだけで、狙った位置へ正確に配置できます。
•	自由な拡大・縮小（ズーム表示）：細かい文字の確認から全体レイアウトの確認まで、倍率を自由に変えてスクロールしながら作業できます。
•	文字化けゼロの高精細保存：日本語フォントのズレや文字化けを起こさず、画面で見えている通りの高画質なPDFとして書き出せます。
🚀 基本の3ステップ（クイックスタート）
1.	ファイルを開く
o	画面左上の 「📂 PDFを開く」 をクリックし、編集したいPDFファイルを選択します。
2.	書き込む
o	上部ツールバーから使いたいツール（文字・四角枠・矢印枠・直線）を選び、PDF上の置きたい場所をクリック（直線はドラッグ）します。
3.	保存する
o	画面左上の 「💾 PDFを保存」 をクリックすると、編集内容が反映された新しいPDFファイル（元ファイル名_edited.pdf）が自動でダウンロードされます。
🛠️ 各種ツールの詳しい使い方
🔍 1. 画面の拡大・縮小（ズーム表示）
細かい文字の書き込みや、ページ全体のレイアウト確認に合わせて表示倍率を調整できます。
•	拡大する（➕ ボタン）：
o	押すごとに 125% ➡️ 150% ➡️ 175% ➡️ 200% と高精細に拡大表示されます。
•	縮小する（➖ ボタン）：
o	押すごとに 75% ➡️ 50% と縮小表示されます。
•	100%（原寸）にリセットする：
o	中央の 「%表示（例: 150%）」 をクリックすると、ワンタップで標準の 100% 表示に戻ります。
•	拡大時のスクロール移動：
o	画面を拡大して用紙が作業エリアからはみ出た場合でも、画面下・画面右のスライダー（スクロールバー）を動かすことで、ページの左端から右端まで切れることなく快適に移動・編集 できます。
•	拡大縮小時のオブジェクト連動：
o	画面を拡大・縮小しても、配置した文字や図形、線の太さは用紙の倍率とミリ単位で完全に連動します。どの倍率で保存しても完成するPDFの画質や位置は常に一定（原寸基準の高画質）に保たれます。
🔤 2. 文字の入力・編集
•	新しく文字を入れる：
1.	ツールバーの 「🔤 文字」 ボタンをクリックします（ボタンが青く点灯します）。
2.	PDF上の文字を入れたい場所をクリックすると文字枠が配置され、枠の左上から自動的に文字入力状態（カーソル点滅） になります。
3.	そのままキーボードで文字を入力します。
•	改行（Enterキー）：
o	文字入力中に Enterキー を押すと改行できます。入力中の文字数や行数に合わせて枠の高さがリアルタイムに下方向へ自然に広がります。
•	後から文字を打ち直す：
o	配置済みの文字枠を 素早くダブルクリック すると、枠内の文字が全選択されて再度編集できます。
•	文字の大きさを変える：
o	文字枠をクリックして選択した状態で、ツールバーの 「文字: [ 18 ] ▼」 からお好みのサイズ（12〜40px）を選びます。
📋 3. 文字列の「履歴」と再利用
書類作成でよく使う文字列やファイル名を、履歴から素早く呼び出して貼り付けることができます。
•	履歴の並び順（3層構造）：
o	一番上：（空欄・新規入力） ➡️ 常に初期状態となっており、新しい文字を打ちたい時に使います。
o	中間：過去に入力した文字列 ➡️ 新しく打ち込んだ文字列が自動的に最大15件まで記憶されます。
o	一番下：📁 [ファイル名] (ファイル名) ➡️ 開いたPDFのファイル名が常に消えずに登録されています。
•	履歴から文字を配置する：
1.	「履歴:」プルダウンから使いたい文字列（ファイル名など）を選びます。
2.	「🔤 文字」 ボタンを押し、PDF上の配置したい場所をクリックします。
3.	配置が完了すると、履歴プルダウンは自動的に一番上の「（空欄）」に戻るため、次回文字を入れる際に前回の文字が邪魔になりません。
•	不要な履歴を消す（履歴削除）：
o	履歴プルダウンから消したい文字列を選び、隣の 「✖ 削除」 ボタンを押します。
o	※「空欄」および「ファイル名」は安全のため削除できないようロックされています。
◻️ 4. 四角枠・➡️ 矢印枠
•	配置方法：
o	ツールバーの 「◻️ 四角枠」 または 「➡️ 矢印枠」 をクリックし、PDF上の置きたい場所をクリックします。
•	大きさの変更（リサイズ）：
o	枠をクリックして選択した際、右下に表示される青い丸印（ハンドル） をドラッグして縦横のサイズを自由に変更できます。
•	向きの変更（ダブルクリック回転）：
o	図形の上で 素早くダブルクリック すると、時計回りに90度ずつクルッと回転 します。
o	四角枠は「横長 ↔ 縦長」、矢印枠は「右 ➡️ 下 ➡️ 左 ➡️ 上」と向きが変わります。
•	塗りつぶし（ベタ塗り）：
o	図形を選択した状態で 「塗りつぶし」チェックボックス にチェックを入れると、選択中の色で中が塗りつぶされます。
📏 5. 直線
•	引き方：
1.	ツールバーの 「📏 直線」 ボタンをクリックします。
2.	PDF上で、線の引き始め位置から引き終わり位置まで マウスをドラッグ（押したまま移動して離す） します。
3.	【便利機能】Shiftキーを押しながらドラッグ すると、完全な水平（真横）または垂直（真下）にピシッと固定されます。
•	長さ・角度の調整：
o	直線をクリックして選択すると、両端に青い丸印が表示されます。この丸印をドラッグすることで、長さを伸ばしたり角度を変えたりできます（調整中もShiftキーが使えます）。
•	全体の移動：
o	直線の中央付近をドラッグすると、直線の長さや角度を保ったまま平行移動できます。
•	90度回転：
o	直線の上で 素早くダブルクリック すると、直線の中心を軸として時計回りに90度回転（水平 ↔ 垂直）します。
🎨 6. 色・太さの変更と「白（目隠し）」機能
•	色を変える：
o	対象のオブジェクトを選択し、ツールバーの丸いカラーボタン（赤・青・黒・緑・オレンジ・白）をクリックします。
•	線の太さを変える：
o	四角枠・矢印枠・直線を選択し、ツールバーの 「太さ: [ 4px ] ▼」（2px / 4px / 7px / 12px）から選びます。
•	【重要テクニック】白色を使った「修正テープ（目隠し）」：
1.	「◻️ 四角枠」を配置します。
2.	カラーパレットで 「白」 を選び、「塗りつぶし」にチェック を入れます。
3.	不要な文字や個人情報の上に重ねると、元の文字を真っ白に隠すことができます。
o	※編集画面では見失わないように「薄い点線枠」が表示されますが、保存した完成PDFには点線は一切出ず、綺麗な白ベタ に仕上がります。

❓ よくある質問・トラブルシューティング
•	Q. 画面を拡大したとき、左側の文字が見えなくなりました。
o	A. 画面下のスライダー（横スクロールバー）を左端までスライドしてください。ページの左端まですべて表示されます。中央の「%表示」を押せばいつでも100%表示に戻せます。
•	Q. 文字を入力しようとすると枠が動いてしまいます。
o	A. 文字枠を素早くダブルクリックしてください。枠内に文字カーソルが入り、文字入力モードになります。
•	Q. 操作を間違えて消してしまいました。
o	A. 慌てずにツールバーの 「↩（元に戻す）」 ボタン（または Ctrl + Z）を押してください。最大30回前まで操作を巻き戻せます。
•	Q. 白い枠を置いたらどこにあるか分からなくなりました。
o	A. 本アプリでは白いオブジェクトにも薄いグレーの点線枠が表示される安全設計になっています。もし選択が外れて見失った場合は、その付近をクリックすると青い枠線が表示されて選択状態に戻ります。
•	Q. 複数ページのPDFにも対応していますか？
o	A. はい。画面右上の「◀」「▶」ボタンでページを切り替えてそれぞれのページに書き込みができます。保存時は全ページが合成されて出力されます。
